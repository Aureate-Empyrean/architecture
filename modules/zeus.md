# Zeus and Dev Orchestrator — private development tooling

**Status:** private internal development tooling. Not a public module, not production-ready, and not described operationally in this public architecture repository.

Zeus and Dev Orchestrator are deliberately separate from Astra and from the public Aureate Empyrean module family. Their source code, local topology, operating policy, security evidence, deployment details and known gaps are maintained only in restricted private repositories. This page records the public boundary only.

- Zeus is an owner-facing development interface; it is not a general ecosystem service.
- Dev Orchestrator is the planning and execution backend behind Zeus.
- Neither component is a public distribution channel or an Exodus production component.
- Their implementation status and operational procedures are intentionally not published here.

This page changes no accepted architecture decision. Public ecosystem modules and shared concepts remain documented elsewhere in this repository.
